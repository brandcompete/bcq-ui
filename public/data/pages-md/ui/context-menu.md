Built on top of three other components - <a v-link href="/ui/card">card</a>, <a v-link href="/ui/list">list</a> and 
<a v-link href="/content/container">container</a>, our context menu can be seamlessly integrated with any other 
<a v-link href="/ui">component</a> or <a rel="noopener" href="https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement" target="_blank">HTMLElement</a> 
and called via <a rel="noopener" href="https://developer.mozilla.org/en-US/docs/Web/API/Element/contextmenu_event" target="_blank">@contextmenu</a>, 
<a rel="noopener" href="https://developer.mozilla.org/en-US/docs/Web/API/Element/click_event" target="_blank">@click</a> 
or any other suitable event.

Right-click on the <a v-link href="/ui/lazy-image">images</a>, <a v-link href="/ui/avatar">avatars</a> and 
<a v-link href="/ui/flag">flags</a> below to view context menus with different setting, icons, etc.
