The <code>avatar</code> component renders either text or image within a circular or tiled container.
Internally, if the <code>src</code> prop is set, <code>avatar</code> is using our <a href="/ui/lazy-image" v-link>lazy-image</a>
component. If you are looking for a way to stack avatars, check our <a href="/ui/avatar-group" v-link>avatar-group</a> component.
