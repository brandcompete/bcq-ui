Becquerel's <code>bc-data-table</code> is a flexible component for displaying large datasets in a responsive
grid/table layout. It includes built-in sorting, filtering and global search, pagination, 
and column visibility controls, making it easy to explore and manage complex data. 
It also supports custom column templates for rendering formatted values, badges, 
icons, actions, or fully custom Vue content, while remaining performant and easy to 
integrate into data-driven applications.
