The <code>flag</code> component is a quick and easy way to add beautiful flags to your projects. The Flag Icons have 
been created by <a href="https://flagicons.lipis.dev/" target="_blank" rel="noopener">Panayiotis Lipiridis</a> and are 
also available on <a href="https://github.com/lipis/flag-icon-css" target="_blank" rel="noopener">GitHub</a>. They are not
included by default in BCQ, so if you plan on using the <code>flag</code> you need to include them from CDN or import them as
a JavaScript module as shown below.
