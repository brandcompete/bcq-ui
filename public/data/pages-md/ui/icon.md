Our default icon font provider is <a href="https://materialdesignicons.com/" rel="noopener" target="_blank">Material Design</a> (<code>'mdi'</code>), 
but you can easily install any other popular font libraries such as <a href="https://fontawesome.com/" rel="noopener" target="_blank">Font Awesome</a>,
<a href="https://fonts.google.com/icons" rel="noopener" target="_blank">Google Icons</a>, etc. and then setting icon's <code>provider</code> 
prop to the correct font prefix (<code>'fa'</code>, <code>'google'</code>, etc.)

Make sure you also check our <a href="/ui/svg-icon" v-link>svg-icon</a> component that uses sprites and allows you to 
add only the icons you need instead of including thousands of unused glyphs.
