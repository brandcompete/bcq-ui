The <code>dialog</code> component informs users about a specific task and may contain critical information, 
require decisions, or involve multiple tasks. Use dialogs sparingly because they are considered obtrusive UI. 
Built on top of our <a href="/ui/card" v-link>card</a>, <a href="/ui/btn" v-link>button</a>, 
<a href="/ui/icon" v-link>icon</a> and <a href="/ui/divider" v-link>divider</a> components and using the
<a href="/directives/scroll-lock" v-link>v-scroll-lock</a> directive internally.
