Our <code>svg-icon</code> is a lightweight <a href="/ui" v-link>component</a> designed to render <a href="/ui/icon" v-link>icons</a> 
from SVG sprites efficiently. Instead of relying on bulky icon fonts with thousands of unused glyphs, it lets developers
include only the specific icons their project needs, reducing bundle size. This approach improves performance and keeps 
asset management explicit and maintainable. It is especially useful in performance-sensitive apps where every kilobyte counts.

For the demo below, we have used icons, provided by <a href="https://www.flaticon.com/" rel="noopener" target="Blank">FlatIcon</a>, 
where you could find virtually any SVG icon you might need.
