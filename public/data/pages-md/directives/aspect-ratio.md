The <code>v-aspect-ratio</code> directive can be used to fix any section to a specific aspect ratio 
regardless of the screen size. To use it, simply add <code>v-aspect-ratio="width/height"</code> to any HTML element or 
Vue component. Internally, <code>v-aspect-ratio</code> is being used in our <a href="/ui/lazy-image" v-link>lazy-image</a> component.
