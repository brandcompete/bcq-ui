The "tooltip", "infotip" or "hint" is a common graphical user interface element. It is used in conjunction with a
<a href="/content/utility-css-classes" v-link>cursor</a>, usually a pointer. In Becquerel, <code>v-toltip</code> is a <a href="/directives" v-link>directive</a>, 
expecting an object, containing optional (default is <code>top</code>) position (<code>'top'</code>, <code>'right'</code>, <code>'bottom'</code> or <code>'left'</code>)
and <code>text</code> of the tooltip. Hover the <a href="/ui/card" v-link>cards</a> on the demo below to see it in action.

In case you are a looking for a more complex and rich-text solution, check our <a href="/ui/tooltip" v-link>tooltip</a> component.
