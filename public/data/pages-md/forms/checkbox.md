The <code>checkbox</code> is a selection control component, similar to the <a href="/forms/switcher" v-link>switcher</a>, 
allowing users to select a single option. This component must be used with the <code>v-model:checked</code> prop as it does not 
maintain its own state. Works great with our <a href="/forms/async-form" v-link>async-form</a> component.
