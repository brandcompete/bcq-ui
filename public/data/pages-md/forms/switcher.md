The switcher is a selection control component allowing users to select a single option,
similar to the <a href="/forms/checkbox" v-link>checkbox</a>. This component must be used with the <code>v-model:checked</code> 
prop it does not maintain their own state. Works great with our <a href="/forms/async-form" v-link>async-form</a> component.
