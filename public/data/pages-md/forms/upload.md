Our async file uploader is using the HTML5 <a href="https://developer.mozilla.org/en-US/docs/Web/API/Blob" target="_blank" rel="noopener">Blobs</a> 
and <a href="https://developer.mozilla.org/en-US/docs/Web/API/FileReader" target="_blank" rel="noopener">FileReader API</a>. 
Built on top of our <a href="/ui/btn" v-link>button</a>, <a href="/ui/list" v-link>list</a>, <a href="/ui/icon" v-link>icon</a>, 
<a href="/ui/avatar" v-link>avatar</a> and <a href="/ui/card" v-link>card</a> components, it is fully customizable 
and offers plenty of options such as mime-type check, preview, multiple/single upload, 
<a rel="noopener" href="https://www.gbmb.org/kb-to-bytes" target="_blank">max-filesize</a> and custom validation messages.
