A customizable range <a href="/forms/slider" v-link>slider</a> component built on top of the native <code>input[type="range"]</code>, extended to support 
two thumbs for selecting value intervals. It provides smooth interactions, accessible keyboard and touch controls. 
The component supports flexible styling and can adapt to different scales, including linear and custom mappings. 
Designed to be lightweight and easy to integrate into modern UI frameworks.
