Our <code>bc-text-field component</code> is an HTML input/textarea on steroids, designed to handle almost any text-entry 
scenario with a single, consistent API. It supports all common input types, including text, password, number, email, tel, date, datetime-local, 
month, etc., as well as multi-line textarea mode (with optional auto-resize). Built-in left and right icons make it easy to add visual 
cues, actions, or status indicators without extra markup. The component provides a flexible, polished foundation for 
<a href="/forms" v-link>forms</a> and data-entry interfaces across your Vue applications.
