The <code>slider</code> component is regarded as a better visualization of the number <a href="/forms/text-field" v-link>input</a>. It is used for gathering numerical user 
data and usable both in <a href="/ui" v-link>ui</a> and <a href="/forms" v-link>form</a> scenarios. Make sure you check 
<a href="/forms/range-slider" v-link>range-slider</a> if you are looking for additional functionality for selecting value intervals.
