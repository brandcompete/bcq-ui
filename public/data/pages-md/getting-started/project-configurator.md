Here you can configure a new Vue 3 + Vite project with BCQ prewired with everything needed to start developing. 
Choose your package manager, project name, theme, language, and optional features such as Vue Router, Axios and Pinia, 
and the matching <a v-link href="/getting-started/">create becquerel</a> command is generated for you. Copy it, paste
it into your terminal, and your project is ready, without answering any questions.
