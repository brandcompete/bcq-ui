The <code>layout</code> component provides a flexible foundation for building application page structures. Along 
with the <a href="/content/app" v-link>app</a> It organizes the interface into a header, footer, main content area, and optional 
left and right sidebar slots. The component supports configurable widths, elevation levels, and smooth animations for 
expanding and collapsing sidebars. Designed for composability and control, it enables developers to quickly 
assemble responsive and interactive application layouts.
