The <code>heading</code> component provides a consistent way to render titles using the predefined 
<a href="/content/typography" v-link>typography</a> treatments of our design system. It supports multiple font 
sizes and styles to match different heading levels and visual hierarchies. The component allows 
configurable padding and margin for flexible spacing within layouts. An optional <a href="/ui/divider" v-link>divider</a> can be displayed to visually 
separate the heading from surrounding content.
