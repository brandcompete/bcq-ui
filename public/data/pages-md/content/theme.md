BCQ supports both light and dark themes, configured at the root application component - the <a href="/content/app" v-link>app</a>. 
Most components automatically adapt based on the theme defined there. By default, the application uses the dark theme, 
but this can be easily changed by setting the <code>dark</code> prop of the <a href="/content/app" v-link>app</a> component to <code>false</code>.

If needed, you can customize the light and dark color definitions in the <a href="/content/css-variables" v-link>variables.css</a> file.
