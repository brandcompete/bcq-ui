Typography is essential for clear communication and visual hierarchy in applications. Properties such as font size, 
alignment, text decoration, and text transform help structure content and guide the user's reading flow. In BCQ, we 
simplify implementation by providing predefined CSS and self-explanatory class names, 
making it easier to apply consistent typography across the application. Many of our components support <code>font-size</code>,
<code>font-weight</code>, <code>text-align</code>, etc. as handy props.
