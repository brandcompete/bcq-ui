The <code>app</code> component is required for all applications built with BCQ. It is the topmost mount point for our 
components and ensures that it propagates the default <a href="/content/theme" v-link>theme</a> to child 
components and much more. It should only be rendered within your application just once.

Make sure you also check the <a href="/content/layout" v-link>layout</a> component, <a href="/content/colors" v-link>colors</a> and <a href="/content/brand-color" v-link>brand-color</a> 
to learn how to create color palettes, which are consistent application-wide.
