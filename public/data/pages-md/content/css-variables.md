The <code>variables.css</code> file (download <a href="/code/variables.css" download>here</a>) centralizes most configurable style values used throughout the library. It contains 
definitions for colors and other non-layout design tokens, allowing developers to easily adjust the visual appearance 
of their applications. By modifying these variables, teams can quickly customize themes and branding without 
changing the core styles. This approach keeps the styling system flexible while maintaining consistency across 
applications built with the library.

Make sure you check our <a href="/getting-started/quick-start" v-link>quick start</a> page to learn how to include
<code>variables.css</code> in your project.
